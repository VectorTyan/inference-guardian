# 版本记录

## 0.28.0

源码、示例目录清单和部署输入分开维护。默认打包使用公开示例，指定 --delivery-dir 时从外部目录读取配置及基础镜像并将产物写入该目录的 dist。打包前在暂存目录验证所有场景。安装参数、守护服务接口、恢复与事务协议沿用既有格式。

## 0.27.3

公开源码使用虚构模型名称和文档专用地址描述四种拓扑。现场配置、运行记录、凭据和构建输入由部署者独立维护。

内置配置集中在宿主工具的 presets 模块，原导入路径和类型保留。命令传输模块独立识别 seccomp 启动错误，探测、比较和事务处理继续使用原有入口。公开 ID 适用于新部署，私有部署升级需沿用原发行线。

离线验证使用标准库测试、临时文件和节点替身，分别核对原配置行为与公开示例。真实 Docker、SSH 和推理服务须由部署方验收。

## 0.4.0

部署根目录集中管理配置、凭据与状态。

## 0.3.0

统一安装入口支持多节点发布和 observe 验收。

## 0.2.1

加强启动来源契约与阶段就绪检查。
