## 0.31.0

新增可选的 P/D 指标接入。Guardian 根据四机部署清单生成 P0 逐端点转发允许列表和 Prometheus 发现配置。标签独立记录角色、逻辑实例、成员与服务器，采集器可通过 Remote Write 将样本上报至 AOM。

P0 支持独立监控端口和转发进程，可以与自愈分开部署。独立模式启停无需重启原推理 Proxy。同端口模式在维护窗口重启 Proxy 加载适配代码。

增加 P0 指标服务部署入口，可联动 BMS 上已运行的 `npu-metrics-monitor` Prometheus。通过本地专用命令校验并热加载，沿用 AOM 写入配置。发现文件更新自动生效。

本地以四机示例的 12 个逻辑端点运行真实 P0 Proxy 和 Prometheus。单个 Decode 目标故障时，本地 Remote Write 接收端记录该目标 `up=0`，其余 11 路指标持续更新，故障解除后恢复 12 路。真实引擎及 AOM 写入需在现场验收。

本次将上述已合入功能正式打包。源码包包含指标生成及部署入口、转发模块和部署文档；现场包继续沿用 local/delivery 中的清单、探针策略及 ARM64 Python 基础镜像。Guardian 升级仍使用原安装入口，指标转发按独立入口部署。
